# Real Bybit Screenshots Demo

This folder is for experimental checks on real Bybit screenshots.

1. These images are not used as the main training dataset.
2. The main Chart Vision model is trained on automatically generated Bybit-style candlestick charts.
3. Real Bybit screenshots are used only to demonstrate how well the model transfers to real UI images.
4. Real screenshots may contain interface panels, labels, axes, volume, order book widgets, and other UI elements.
5. Results on these images are experimental.
6. To test them, place PNG/JPG/WebP images in `raw/` and run:

```bash
python manage.py predict_real_bybit_screenshots
```

Predictions are written to `predictions/real_screenshot_predictions.csv`.
